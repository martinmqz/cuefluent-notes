# Cuefluent Notes marketplace has moved to main

New releases are distributed from the repository's `main` branch. This former
`marketplace` branch is retained for existing installations but receives no new
plugin versions. Refreshing a registration that still selects this branch will
not upgrade it to a newer release.

Follow the [one-time marketplace migration instructions](https://github.com/martinmqz/cuefluent-notes#switch-an-older-marketplace-registration-to-main)
to register `main` in Codex or Claude Code. Keep your notes, workflow settings and
evidence storage; fresh setup is not required for this branch change.

New users should use the [current installation instructions](https://github.com/martinmqz/cuefluent-notes#from-the-marketplace).
A published release reaches the main marketplace after its package-update PR is
reviewed and merged.

# Cuefluent Notes 0.15.1

Claude Code plugin, optional hook-enabled package. Requires Node.js 22 or later on the host PATH. Runtime dependencies and their license notices are included.

Source-available under the [Sustainable Use License 1.0](LICENSE.md). See the [licensing summary](skills/cuefluent-notes/README.md#license) for permitted use and the scope of the license.

For a fresh installation or an upgrade from v0.7.1 or earlier, start a fresh task and ask **Set up Cuefluent Notes** to choose collection and processing separately. Existing workflow users must follow the [coordinated upgrade steps](skills/cuefluent-notes/references/setup.md#existing-settings) before updating clients that share storage; preserve existing settings and paths. Read the [setup guide](skills/cuefluent-notes/references/setup.md), [usage guide](skills/cuefluent-notes/README.md), and [distribution instructions](skills/cuefluent-notes/references/distribution.md). Building or copying this package does not install or trust it. Session collection remains disabled without a separate private configuration and client trust.
